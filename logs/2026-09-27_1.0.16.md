# 简播 1.0.16 维护日志

日期：2026-09-27

## 实机反馈

用户在 1.0.15 中切换“播放方向”按钮后，再打开视频会直接闪退。

## 根因

`PlayerScreen.kt` 中新增的 `applyPlaybackOrientation(video)` 辅助函数被错误改写成了调用自己：

```kotlin
fun applyPlaybackOrientation(video: VideoItem?) {
    applyPlaybackOrientation(video)
}
```

进入播放器后方向 effect 会调用该函数，立即造成无限递归并最终触发 StackOverflow，因此表现为打开播放文件直接闪退。

## 1.0.16 修复

1. 将辅助函数恢复为真正设置方向：
   `targetLandscape = orientationTarget(orientationMode, naturalLandscape(video))`。
2. `selectVideo()` 统一调用该辅助函数。
3. 每次首次进入、自动连播、手动上一条/下一条仍重新应用当前三态方向策略。
4. 移除重复的 `LaunchedEffect(orientationMode, currentIndex)`，避免同一视频切换时两个 effect 同时写方向状态。
5. Media3 继续强制 `RESIZE_MODE_FIT`；VLC 继续自动缩放并保持原始宽高比，不允许拉伸铺满。
6. 新增 `PlaybackOrientationCrashRegressionTest`：
   - 辅助函数内部禁止再次出现自调用；
   - `selectVideo()` 必须通过统一辅助函数应用方向。
7. 版本升级：
   - versionName = 1.0.16
   - versionCode = 17
8. 正式签名仍仅使用 Google Drive `签名文件/简播签名.zip`，不得把 keystore/密码/私钥写入公开仓库。
