# 简播 1.0.13 维护日志

日期：2026-09-21

1. 基线为公开库 main 的简播 1.0.12（versionCode=13），本次版本升级为 1.0.13 / versionCode=14，applicationId 保持 com.luxiaoshi.jianbo。
2. 新增播放画面整屏横向拖动控制进度：向右拖动前进、向左拖动后退；不使用固定秒数，而按“当前屏幕拖动距离 / 当前屏幕宽度 × 当前视频总时长”连续换算，所以横屏、竖屏以及反向横屏都会按当前画面宽度自动适配。
3. 横向拖动与原竖向手势做方向锁定；原竖屏上下滑切视频、横屏左侧亮度/右侧音量/中间上下切视频继续保留。
4. 横向拖动过程中显示目标播放时间，松手后一次性 seek；底部进度条、前后 5 秒按钮、倍速、暂停和控制栏自动隐藏继续保留。
5. 新增 PlaybackProgressStore，按视频稳定标识保存断点。应用退出、切换上一部/下一部、播放器进入后台和播放过程中都会保存当前位置。
6. 再次点入未播放完的视频时恢复上次进度；Media3 与 VLC 两条播放后端均接入恢复逻辑。
7. 只有收到视频自然播放结束并自动进入下一部时，才清除该视频的断点；因此该视频以后再次点入从 0 开始。手动切换视频不会被当作“播放完”。
8. 新增 PlayerInteractionLogicTest，覆盖横向拖动比例换算、0/结尾边界夹取和已播放完视频不从结尾恢复。浮点比例换算最终使用 Double + round，避免 Float 截断造成 1 ms 偏差。
9. 将历史构建时才应用的 tools/v108-controls.patch 正式物化到 PlayerScreen.kt，并删除该补丁，避免正式源码与实际构建行为不一致。
10. GitHub runner 当前的 android-actions/setup-android@v3 会尝试安装已不存在的旧 tools 包，因此正式 android.yml 改为直接下载 Google 官方 command-line tools，再安装 Android API 36 / Build Tools 36.0.0；同时加入 Debug/Release 单元测试和 APK 包名/版本校验。
