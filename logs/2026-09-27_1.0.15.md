# 简播 1.0.15 维护日志

日期：2026-09-27

## 用户需求

1. 初始页面右上角、刷新按钮左侧新增“播放页面设置”按钮。
2. 播放页面设置为三态循环：自适配（默认）→ 默认竖屏 → 默认横屏 → 自适配。
3. 三个状态使用不同图标：自适配为旋转屏幕图标，竖屏为竖向手机图标，横屏为同一手机图标旋转 90°。
4. 初始页面右上角、播放页面设置按钮左侧新增“文件夹排序”按钮。
5. 文件夹排序为两态：当前默认顺序（默认）↔ 最近播放优先。
6. “最近播放优先”只改变文件夹卡片顺序，不改变任何文件夹内部视频顺序。
7. 两个新按钮的图标尺寸与原刷新按钮一致，保持软件现有蓝色体系。
8. 所有改动、测试、构建和签名结果必须写入 GitHub 公开库日志。
9. 正式签名继续只使用 Google Drive“签名文件/简播签名.zip”，签名材料不得进入公开 GitHub。

## 代码改动

1. 新增 `player/PlaybackOrientationMode.kt`：
   - `ADAPTIVE`
   - `PORTRAIT`
   - `LANDSCAPE`
   - 三态循环函数 `nextPlaybackOrientationMode`
   - 播放目标方向函数 `orientationTarget`
2. 新增 `JianboPreferences.kt`：
   - 持久保存播放方向模式；
   - 持久保存文件夹排序模式；
   - 按文件夹 key 保存最近一次实际开始播放时间；
   - `sortGroupsForDisplay` 仅对文件夹列表排序，保持 `VideoGroup.videos` 原对象和原顺序。
3. `MainActivity.kt`：
   - 顶栏顺序固定为“文件夹排序 → 播放方向 → 刷新 → 恢复隐藏分组（若存在）”；
   - 默认排序图标使用蓝色 Sort，最近播放优先使用蓝色 History；
   - 自适配使用 ScreenRotation，竖屏使用 PhoneAndroid，横屏使用 PhoneAndroid 旋转 90°；
   - 所有图标使用与刷新按钮相同的 Compose Icon 默认 24dp，并统一 `MaterialTheme.colorScheme.primary` 蓝色；
   - 只有真正开始播放某文件夹内视频时才更新该文件夹最近播放时间。
4. `PlayerScreen.kt`：
   - 自适配继续沿用原有视频宽高/旋转信息判断；
   - 默认竖屏和默认横屏会在进入视频、切换视频时强制对应方向；
   - Media3 视频尺寸回调仅在自适配模式下允许重新判断方向；
   - 播放页原有手动横竖切换按钮保留。
5. `ExternalOpenActivity.kt`：
   - 外部打开视频同样读取已保存的播放方向偏好。
6. 版本升级：
   - versionName = 1.0.15
   - versionCode = 16
7. CI 的包版本校验同步升级到 1.0.15 / 16。
8. 新增测试：
   - `PlaybackOrientationModeTest`
   - `FolderSortLogicTest`
   - `ToolbarSettingsContractTest`
