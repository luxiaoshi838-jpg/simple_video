# 简播 1.0.14 维护日志

日期：2026-09-22

1. 基线：公开库 main 的简播 1.0.13，applicationId=com.luxiaoshi.jianbo。
2. 用户实机反馈：左右滑动控制播放进度时，屏幕中央会短暂出现黑色长方形浮层，内部显示无意义英文/字符。
3. 根因：1.0.13 横向 seek 复用了播放器中央 overlay，并把目标时间字符串写入 overlay；同时 1.0.13 迁移时亮度/音量提示字符串残留了转义符。
4. 1.0.14 修复：DragAxis.HORIZONTAL_SEEK 分支不再向 overlay 写任何内容；手势一旦判定为横向 seek，会先 overlay=null，清掉可能残留的中央提示。
5. 横向拖动时仍只更新 isSeeking、seekPreviewMs；底部进度条与当前时间继续实时反映目标位置，松手后一次性 seek。
6. 原竖向亮度、音量、上下切视频手势保持不变；亮度/音量 overlay 字符串已恢复正常 Kotlin 插值。
7. 版本升级：versionName=1.0.14，versionCode=15。
8. 新增 PlayerSwipeOverlayContractTest：横向 seek 分支禁止出现 overlay=；判定横向时必须清空已有 overlay。
9. 分支 CI run 35623070681 / job 106410631400 完整成功：Android 36、Gradle、Debug/Release 单测、Release 构建、package/version 校验、artifact 上传全部通过。
